渠道切换

Claude Code 模型名配 auto 后，在这里点一下即可切换，无需重启。

客户端接入示例（Claude Code）

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://<your-api-host>",
    "ANTHROPIC_API_KEY": "<your gateway token>",
    "ANTHROPIC_MODEL": "auto[1m]",
    "ANTHROPIC_SMALL_FAST_MODEL": "auto[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "auto[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "auto[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "auto[1m]",
    "ANTHROPIC_DEFAULT_MODEL": "auto[1m]",
    "CLAUDE_CODE_SUBAGENT_MODEL": "auto[1m]"
  }
}
模型名里的 [1m] 是 Claude Code 的 1M 上下文窗口标记，上行前它自己会剥掉，网关按前缀路由不受影响。curl 手测勿发带 [1m] 的字面模型名。
